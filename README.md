## 📁 Repository Structure
Each subfolder contains:
* `Dataset.csv` / Excel raw source file
* `.pbix` Power BI interactive workbook
* `dashboard_preview.png` High-resolution dashboard capture
* `README.md` Detailed business findings, DAX documentation, and data transformation steps.
